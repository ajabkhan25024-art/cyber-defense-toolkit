# Cyber Defense Toolkit

A collection of simple Python scripts for learning cybersecurity fundamentals — built and tested on Termux (Android).

## ⚠️ Legal Notice
These tools are for educational purposes and authorized testing only. Only use them on systems you own or have explicit permission to test. Unauthorized scanning is illegal.

## Scripts

- **port_scanner.py** — Checks which ports are open on a given target
- **local_scanner.py** — Scans devices on the local network
- **check_password.py** — Checks password strength
- **hash_test.py** — Demonstrates hashing (MD5/SHA256) concepts

## Requirements
- Python 3
- Termux (or any Linux environment)
